Preguntas sobre HTML

¿Qué diferencia existe entre un frame y un iframe?

Un frame permite dividir la ventana del navegador en varias zonas, cada una con una página HTML. Un iframe inserta otra página dentro del contenido de una página HTML.

¿Por qué los frames tradicionales dejaron de utilizarse?

Porque dificultaban la navegación, la accesibilidad, el diseño adaptable y la gestión de las páginas. Además, fueron eliminados de HTML5.

¿Qué ventajas ofrece una plantilla?

Permite reutilizar una estructura común en varias páginas, mantener un diseño uniforme y ahorrar tiempo al crear o modificar el sitio.

¿Qué problemas de seguridad pueden aparecer al utilizar iframes?

Pueden mostrar contenido malicioso o engañoso, facilitar ataques de phishing o clickjacking y cargar páginas externas poco fiables. Se recomienda limitar su uso y aplicar atributos de seguridad como sandbox cuando corresponda.

¿Qué alternativas modernas existen para reutilizar componentes de una interfaz?

Se pueden utilizar componentes de frameworks como Angular, React o Vue, Web Components y plantillas del lado del servidor.
